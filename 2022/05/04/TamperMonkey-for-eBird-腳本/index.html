TamperMonkey for eBird 腳本

發表於 2022-05-04 更新於 2026-11-12

前言

eBird 開放賞鳥紀行功能後，可以透過網址取得行程內所有 Checklist 的編號：

https://ebird.org/tripreport-internal/v1/locations/[TRIP ID]

有人提出：能不能一次抓下全部資料，輸出成像 MyEBirdData 那樣的完整格式？

早期我做過 Chrome 外掛，但沒有上架，安裝和更新都不方便。後來改用 Tampermonkey 使用者腳本，只要點一個連結就能安裝，更新也由 Tampermonkey 處理。

現在原本分開的四支腳本（賞鳥紀行、記錄清單、軌跡、群組分享）已整合成**一支 ebird-kenny**，安裝一次就有全部功能。

功能

頁面 功能
我的清單 /mychecklists 每筆清單前多一個勾選框，勾選任意多筆後一次下載成 Excel。每筆也會多一個日期按鈕，點一下就複製該清單編號（SID）。
我的行程報告 /mytripreports 每個行程旁多一個「下載」按鈕，一鍵抓下行程內所有清單，合併成一個 Excel。
清單分享頁 /checklist/* 側欄多一個「群組通訊錄」，可以存常用群組，分享清單時一鍵填入成員的 eBird ID。
含 GPS 軌跡的清單頁 /checklist/* 軌跡圖旁多一個「下載軌跡」按鈕，輸出 .kml 檔。

「我的清單」頁面裝好腳本後的樣子：每筆清單前有勾選框，日期旁有「複製 SID」按鈕。

含 GPS 軌跡的清單頁，軌跡圖下方會出現「下載軌跡」按鈕：

Excel 欄位對應 eBird 官方匯出格式，包含物種、學名、數量、地點與座標、日期時間、調查方法、繁殖代碼和備註等，完整欄位請看專案說明。

.kml 可以直接匯入 Google Earth、Google 我的地圖、Garmin BaseCamp / Connect、OsmAnd 和 CalTopo。

安裝

步驟 1：安裝 Tampermonkey

到 Tampermonkey 官網，選你的瀏覽器安裝。支援 Chrome、Edge、Firefox 和 Safari。

新版 Chrome、Edge 需要另外開啟「允許使用者指令碼」或「開發人員模式」，否則腳本裝得起來卻不會執行。詳細圖文步驟請看兩棲志工蛙類調記錄器這篇的「電腦端：批次上傳外掛」。

步驟 2：安裝 ebird-kenny 腳本

點下面的連結，Tampermonkey 會跳出安裝頁面，按「安裝」即可：

ebird-kenny.user.js

如果點了只看到一頁程式碼，代表 Tampermonkey 沒有接手，請回頭確認步驟 1 的權限設定。

裝好後，點瀏覽器工具列的 Tampermonkey 圖示，選「管理面板」，確認 ebird-kenny 的開關是開啟（綠色）：

以前裝過四支舊腳本（ebird-trip、ebird-checklist、ebird-track、ebird-users-group）的話，請到 Tampermonkey 管理面板把它們關掉或刪除，避免跟新腳本重複。

初始設定

第一次使用要做兩件事，都在「我的清單」或「我的行程報告」頁面上進行。

1. 輸入 eBird API 金鑰

  1. 到 ebird.org/api/keygen 申請金鑰（需要登入 eBird）。
  2. 把金鑰貼到頁面上方的欄位，按「儲存」。

2. 下載鳥名錄

  1. 選擇名稱的顯示語言：中文俗名或英文俗名。
  2. 按「下載鳥名錄」，等幾秒就完成，資料會存在瀏覽器裡。

想換語言的話，清除瀏覽器 localStorage 裡的 sp_info，再重新下載鳥名錄。

資料與隱私

所有資料只存在你自己的瀏覽器，不會傳到任何第三方伺服器。腳本只會連線到 eBird（ebird.org、api.ebird.org）。

localStorage 項目 內容
ebirdKey eBird API 金鑰
sp_info 鳥名錄快取
ebird-groups 群組通訊錄

換電腦或換瀏覽器時，這些設定不會跟著走，需要重新設定。

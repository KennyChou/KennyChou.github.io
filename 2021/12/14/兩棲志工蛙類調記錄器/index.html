兩棲志工蛙類調記錄器

發表於 2021-12-14 更新於 2026-11-12

前言

兩棲志工夜間調查常遇到又濕又雨的天氣：一手撐傘、嘴裡咬著手電筒，還要顧著不讓記錄紙淋濕。回家後紙本資料要上傳，又得回想那晚記的是哪種蛙、辨認自己的字跡；筆數一多，只能一筆一筆點滑鼠到天亮。

蛙記錄 APP 讓你在野外直接用手機記錄，回家後產生 Excel，再透過電腦端外掛一次批次上傳到兩棲上傳資料平台。

如果你已熟悉紙本記錄與後台回傳流程，這個工具很快就能上手，也能順便解決一直放在抽屜裡的舊記錄。

整體流程：

  1. 野外：用手機 APP 記錄
  2. 回家：APP 匯出 Excel
  3. 電腦：安裝 Tampermonkey 與 froghome-import 腳本
  4. 在上傳平台選擇 Excel，批次上傳

手機安裝

Android：Play 商店

Google Play 搜尋「蛙記錄」或「froghome」，或直接開啟連結：

iPhone：PWA 網頁應用程式

受限於 iOS 上架費用與開發設備，iPhone 目前使用 PWA（可加到主畫面的網頁應用程式）。若累積了不少紙本記錄，也可以在電腦上用同一個網頁輸入，再用外掛上傳。

  • 舊版：用 Safari 開啟 https://froghome-tw.web.app

電腦端：批次上傳外掛

APP 產生的 Excel 要靠電腦瀏覽器的外掛才能上傳，所以需要先安裝 Tampermonkey（管理瀏覽器腳本的外掛），再安裝 froghome-import 腳本。

限制： 只能在 Windows、macOS（或 Linux）電腦上操作，手機與平板無法使用。瀏覽器可用 Google Chrome、Microsoft Edge 或 Firefox。

步驟 1：安裝 Tampermonkey

依你的瀏覽器選擇：

瀏覽器 安裝連結
Chrome Chrome 線上應用程式商店
Edge Microsoft Edge 附加元件
Firefox Firefox 附加元件
  1. 開啟上面的連結，按「加到 Chrome」（Edge 為「取得」，Firefox 為「新增至 Firefox」）。
  2. 跳出確認視窗時按「新增擴充功能」。
  3. 安裝完成後，瀏覽器右上角會出現 Tampermonkey 圖示（黑底、兩個圓點）。若看不到，點網址列右邊的拼圖圖示，再按圖釘把它固定在工具列。

步驟 2：開啟使用者腳本權限（Chrome、Edge 必做）

新版 Chrome、Edge 預設會擋掉使用者腳本，沒做這一步，腳本會安裝成功卻不會執行。

  1. 在網址列輸入 chrome://extensions（Edge 輸入 edge://extensions）。
  2. 找到 Tampermonkey，按「詳細資料」。
  3. 依你的瀏覽器版本，開啟下列其中一個選項：
    • 打開「允許使用者指令碼」（Allow User Scripts）開關。
    • 找不到這個開關的話，回到 chrome://extensions 頁面，打開右上角的「開發人員模式」。

Firefox 不需要這一步。

繁體中文版 Chrome 會把 Tampermonkey 顯示為「篡改猴」，是同一個外掛。

步驟 3：安裝 froghome-import 腳本

  1. 點這個連結：froghome-import.user.js
  2. Tampermonkey 會自動開啟安裝頁面，顯示腳本名稱與說明。
  3. 按「安裝」（Install）。
  4. 看到「已安裝」或腳本出現在清單中，就完成了。

如果點連結後只看到一整頁程式碼，代表 Tampermonkey 沒有接手：確認步驟 1、2 都完成，並重新整理瀏覽器後再點一次連結。

步驟 4：確認腳本已啟用

  1. 點工具列的 Tampermonkey 圖示，選「管理面板」（Dashboard）。
  2. 在「已安裝的腳本」清單找到 froghome-import。
  3. 確認最左邊的開關是開啟（綠色）。
  4. 之後有新版腳本時，Tampermonkey 會自動提示更新，按「更新」即可。

步驟 5：上傳記錄

  1. 在手機蛙記錄 APP 產生下載記錄 Excel，傳到電腦。
  2. 開啟兩棲上傳資料平台，進到「新增記錄蛙種」畫面。
  3. 畫面上會多出「上傳 EXCEL 輔助程式」區塊。
  4. 選擇剛才的 Excel，執行批次上傳。
  5. 等每一筆的狀態最後都變成 OK 即可。

常見問題

  • 平台頁面沒有出現「上傳 EXCEL 輔助程式」： 檢查步驟 2 的權限是否開啟、步驟 4 的腳本開關是否為綠色，然後重新整理平台頁面。
  • 某幾筆沒有變成 OK： 先確認該筆的蛙種、日期、座標在平台上能正常手動新增，再單獨重傳那幾筆。
  • 舊版 Tampermonkey 裝不起來： 先更新瀏覽器到最新版再試。
